# JavaScript Todo List

A single-page task-list exercise built with HTML, CSS and vanilla JavaScript.

## Features

- Add tasks with a description.
- Choose Study, Work or Personal categories.
- Delete tasks and view the total task count.
- Save and load tasks using browser local storage.

## Run

```bash
git clone https://github.com/sangeethareddy9/Frontend-project2.git
cd Frontend-project2
```

Open `index.html` in your browser. No build step or backend is required.

## Source

[index.html](index.html) contains the markup, styles and JavaScript. This exercise practices forms, arrays, DOM updates and local storage.

For the React version with additional controls, see [Smart Todo Manager](https://github.com/sangeethareddy9/react-todo-app).
